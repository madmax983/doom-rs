## 2023-11-20 - Prevent Deadlock and OOM in Audio and Map Parsing
**Learning:** Found two key vulnerabilities in the Doom Rust architecture. First, an OOM vector in `doom-map` parsing `UDMF` levels where excessively long un-bound strings or repeated identical fields in blocks could cause unbounded memory allocations, exhausting resources and panicking. Second, a deadlock and race condition within `doom-audio`'s `SfxMixer` interacting with channels due to priority locking logic.
**Action:** Always ensure fuzzed parsers enforce strict data-size bounds on input (e.g. `fields.len() > 100_000` clamping) and verify that all multi-threaded environments and event loop hooks are fully synchronized, verifying fixes directly using `loom` and `cargo-fuzz`.
