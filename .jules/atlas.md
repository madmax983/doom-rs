**[Remove Redundant Linedef Dispatch]**
**Tangle:** The `doom-game/src/specials.rs` file contained a massive ~1400-line legacy `activate_linedef` dispatch system that practically perfectly duplicated the logic in `linedef_dispatch.rs`. This created "The Blob" anti-pattern and a "Shotgun" maintenance hazard since adding a new linedef effect required updating both files.
**Blueprint:** Removed `activate_linedef` and all its helper functions (`activate_doors`, etc) from the production logic scope by moving them entirely into the `#[cfg(test)]` module as legacy shims for the existing test suite. Also fixed `linedef_dispatch.rs` edge cases for blazing fast doors, keyed fast doors, and turbo stairs with crush damage.
