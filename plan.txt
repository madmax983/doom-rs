```
🎨 Mosaic: UI Polish for CLI Output

🖌️ **Before:**
The CLI output raw JSON via manual string building for map statistics, pathfinding, tactical analysis, and engine errors. This was prone to escaping bugs, complex logic (e.g., custom string iterators for arrays), and resulted in fragile, un-formatted JSON strings output to the console.

✨ **After:**
The CLI commands `--json`, `--analyze`, `--map-stats`, and error handlers now utilize `serde_json` to securely construct structured JSON payloads. This guarantees proper escaping, well-formed arrays, and outputs formatted, readable JSON (`to_string_pretty`) where beneficial.

🖼️ **Visuals:**
JSON outputs for `map-stats`, `pathfind`, and `analyze` are now robustly structured arrays/objects, eliminating manual string parsing constraints and allowing clean integrations for automated tooling.
```
