💡 What: Replaced `Vec` with `SmallVec` as the return type in `sectors_by_tag`.
🎯 Why: `sectors_by_tag` is called heavily during linedef dispatch (e.g., doors, stairs, crushers) and returning a standard `Vec` caused unnecessary heap allocations on a hot path. Since tags usually map to only a few sectors (often 1-4), a `SmallVec<[usize; 4]>` eliminates heap allocation entirely for the vast majority of calls.
📊 Impact: Eliminates short-lived heap allocations during most cross-line triggers and linedef activations that lookup sectors by tag.
🔬 Measurement: Run `cargo bench` and observe improvements in memory profiling during `ev_build_stairs` and door operations. Alternatively, use standard performance profiling tools (like `perf` or `samply`) on a busy map segment where multiple doors or stairs are activated per tic.
